# pair-wise-yy-61 航空器定检工作包执行与放行审阅平台

支持工卡依赖、测量值容差校验、离线暂存、冲突提交提示、分阶段签字、版本差异和放行锁定。超差项目必须由授权人员处理后才能继续。

## 超差处置链

超差工卡、工程指令、阶段签字与放行基线已接成一条处置链：

- 授权时必须登记工程指令号与修订号，仅当前有效修订的工卡才能继续；
- 指令改版或撤销后，相关工卡、授权、阶段签字与放行基线立即失效重算，原始测量值保留；
- 两人同时提交同一指令时先到生效、后到保留为冲突（工程指令页可模拟）；
- 提交失败按原授权号恢复，不重复记审计；
- 旧数据没有修订号的记录按首版 R1 兼容。

## 技术栈

React、Fluent UI、Redux Toolkit、React Router、RTK Query、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62061`。工卡草稿和审计操作保存在 `localStorage`。

```bash
npm run build
```
